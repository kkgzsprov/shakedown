## 용어

| 용어 | 뜻 |
|---|---|
| 실행(run) | 시작부터 사망, 탈출, 시간 제한까지 이어지는 게임 세션 하나 |
| 배치(batch) | 시드, 프로필, 맵, 튜닝 후보에 걸친 실행 묶음 |
| 캠페인(campaign) | 승인된 목표를 향한 여러 배치. 배치 사이에 플래너가 계획을 고친다 |
| 플래너(planner) | System 2: 배치 사이에 계획하고 보고하는 LLM |
| 디사이더(decider) | System 1: 결정 시점마다 합법적 후보 하나를 고른다 |
| 실행기(executor) | 선택을 매 스텝 입력으로 바꾸는 게임 쪽 코드 |
| 어댑터(adapter) | 게임 쪽 Shakedown 코드 전체: 관측, 후보, 실행기, 반사(reflex), 오라클(oracle), 일시정지 |
| 후보(candidate) | 몇 초 길이의 합법적 행동. 종류와 대상으로 이름을 붙인다 |
| 결정 시점(decision point) | 어댑터가 멈추고 디사이더에게 묻는 순간 |
| 테이프(tape) | 한 실행에서 기록한 답들. 디사이더 백엔드 없이 그 실행을 재생하는 데 쓴다 |
| 입력 기록(input recording) | 실행기가 주입한 모든 입력 이벤트. 디사이더 없이 실행을 재생하는 데 쓴다 |
| 프로필(profile) | 플레이어 기질: 플래너 지시문과, 반응 지연 같은 실행기 제한 |
